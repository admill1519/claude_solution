     1→# Workspace Python Environments
     2→
     3→This workspace provides two Python environments for different use cases.
     4→
     5→- **`py3.10-exercises/cd14715-claude-code-classroom/`** → Runs in the system Python 3.10 (no activation needed)
     6→
     7→- **`py3.13-exercises-and-project/`** → Must run in the Python 3.13 virtual environment (`source /voc/data/py313-venv/bin/activate`)
     8→
     9→**Quick Reference**
    10→
    11→| Task | Command |
    12→|------|---------|
    13→| Use system Python (3.10) | `python` (default) |
    14→| Activate Python 3.13 | `source /voc/data/py313-venv/bin/activate` |
    15→| Deactivate Python 3.13 | `deactivate` |
    16→| Check Python version | `python --version` |
    17→| Run Python 3.13 exercises | Activate venv, then run exercise commands |
    18→| Run Python 3.10 exercises | Use default Python without activation |
    19→

    65→## 2. Python 3.13 Virtual Environment
    66→
    67→A Python 3.13 virtual environment is available with modern tooling packages (anthropic, pytest, mypy, ruff, etc.).
    68→
    69→**To activate the Python 3.13 environment:**
    70→```bash
    71→source /voc/data/py313-venv/bin/activate
    72→```
    73→
    74→After activation, your prompt will change to show `(py313-venv)` and Python commands will use version 3.13:
    75→```bash
    76→python --version
    77→# Python 3.13.18
    78→```
    79→
    80→**To deactivate and return to system Python:**
    81→```bash
    82→deactivate
    83→```
